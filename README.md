# 淮海战役 1948 · 亲历战场

> 一个完全离线的单文件 3D 兵棋网页：把 1948 年冬天那 66 天，摆成一张可以俯身去看的沙盘。
>
> A single-file, fully offline 3D wargame-style web page about the Huaihai Campaign (Nov 1948 – Jan 1949). No CDN, no fonts, no images, no audio files — just one `index.html`.

双击 `index.html` 即可运行，不需要联网、不需要安装、不需要构建。也可直接部署到 GitHub Pages（见文末）。

## 它是什么

把淮海战役的三个阶段（碾庄圩 → 双堆集 → 陈官庄）做成一张 3D 沙盘。地形、河流、铁路、村落、合围圈、进攻箭头、炮火覆盖，全部按战役日期逐日推进；24 支真实番号的部队会在这一天该在的位置上，被歼灭的部队留在地图上变成一枚「被歼」标记。

| 沉浸层 | 说明 |
| --- | --- |
| 序幕 | 打开先是一屏 `1948.11.6` 的黑场，点「进入战场」后镜头从 620 km 高空俯冲落入徐州以东。 |
| 天色 | 初冬黄昏的暖褐 → 十二月的阴冷青灰 → 一月的雪夜深蓝，按战役第几天连续插值，不是三段硬切。压平视角会看到云、日轮或月轮、后期星野。 |
| 大气透视 | 地平线与远山之间压一层雾，俯角越低雾越重，沙盘边缘不再露黑。 |
| 雪 | 12 月中旬起飘雪，1 月最密；两遍批量矩形绘制，掉帧风险很低。 |
| 木框淡出 | 视角压到接近地面时，沙盘木框淡出——它从「桌上的一只模型」变成「你脚下的战场」。 |
| 音场 | 棕噪声合成的风声、随机触发的低频炮声、界面短音，全部 WebAudio 现场生成。默认开，需一次点击后才会响。 |
| 章节字幕 | 每揭开一层，屏幕中段压一行「第壹章 / 战略态势 / 1948.11.6」的大字，3.4 秒淡出。 |
| 打字机叙事 | 底部叙事条逐字打出，日期用砖红突出。 |
| 光柱与情报条 | 悬停番号牌时牌下有一道暖色光柱落地，牌上方浮出「此刻在做什么」的短情报（取自该部队当日态势）。 |
| 拖拽惯性 | 松手后视角继续滑一段再停，像转动一只真的沙盘。 |
| 终局 | 走到 `1949.1.10`，全屏压暗浮出纪念碑：歼敌 555,099、我军伤亡 134,000、支前民工 5,430,000、66 天。 |
| 沉浸模式 | `H`：收起所有面板、图例、时间轴，只留上下电影黑边。 |

## 玩法

| 操作 | 效果 |
| --- | --- |
| 左键拖拽 | 绕沙盘旋转视角（上下拖 = 压平 / 抬高俯角） |
| 滚轮 / 双指捏合 | 推近、拉远（40 — 470 km） |
| 右键拖拽 或 `Shift` + 拖拽 | 平移沙盘 |
| 单击番号牌 | 展开部队档案（主官、兵力、编制、当日态势、结局），镜头同时推近 |
| 双击番号牌 | 镜头贴到该部队（68 km，接近地面） |
| 双击空地 | 镜头落到点击的地面位置，俯角压到贴地 |
| 推近到约 252 km 以内 | 战场浮出金色 `?` 光点，点击翻开一段真实故事 |
| 底部时间轴 | 拖动即可在 `1948.11.6 — 1949.1.10` 的 66 天里来回推演 |
| 播放 / 暂停 | 战役自动推进，四层态势随时间逐层揭开 |
| `H` / `M` / `V` | 沉浸模式 / 静音 / 一键贴地 |
| `Space` `←` `→` `1`–`4` `Esc` | 播放暂停 / 单日步进 / 切换态势层 / 关闭卡片 |

**想把沉浸感拉满**：`V` 贴地 → `H` 进沉浸 → 时间轴拖到 12 月以后，等雪落下来。

### 深链

URL 支持深链，可直接定位到某个时刻（方便备课或分享）：

```text
index.html#d=39&l=3          第 39 天（12 月 15 日，双堆集覆灭）· 第三层态势
index.html#d=0&l=1&u=km-7    同时打开某支部队的档案
index.html#d=20&l=2&s=s7     同时打开某段故事
```

带深链打开时会自动跳过序幕，镜头不再俯冲。

## 里面有什么

- **四层态势**：战略态势 → 碾庄圩（围歼黄百韬第 7 兵团）→ 双堆集（围歼黄维第 12 兵团）→ 陈官庄（围歼杜聿明集团）。点「揭开下一层」逐层展开，镜头自动落到该阶段的核心战场。
- **24 支真实番号的部队**：华野 9 支、中野 3 支、国民党军 12 支。每支都有主官、兵力、编制、当日态势与最终结局。
- **三阶段合围圈**：随日期缓缓收拢，收拢到零就变成一枚叉。
- **进攻箭头与炮火覆盖**：哪个方向在打、哪里在被炮击，随日期出现与消失。
- **11 段真实故事**：十人桥、贾汪起义、攻克宿县、总前委、徐东阻击战、廖运周起义、大王庄血战、543 万支前、黄百韬之死、黄维被俘、陈官庄最后一夜。凑近点击才会翻开。
- **史料与数据核对**（右上角按钮）：一张逐条核对表 + 三处最容易被误传的细节。
- **23 条大事记**：随日期在叙事条里滚动出现。

## 史料与口径

时间、番号、兵力与战果，以《中国人民解放军战史》第三卷、《淮海战役》（中共党史出版社）、《淮海战役支前史料选编》、《粟裕战争回忆录》、《杜聿明回忆录》及淮海战役纪念馆展陈资料为准。

- 歼敌总数 **555,099 人**（1 个「剿总」前进指挥部、5 个兵团部、22 个军部、56 个师）。
- 三个阶段歼敌约 **17.8 万 / 11.8 万 / 26 万**。
- 支前民工 **543 万人**、大小车 **88.1 万辆**、担架 **20.6 万副**、粮食 **9.6 亿斤** ——「543 万小推车」其实是两个数字合并后的说法，页面里分开写。
- 黄百韬死因有自杀、阵亡两说，沙盘采自杀说并在故事里注明。
- **部队在沙盘上的位置是按战役进程逐日推移的示意**，方位力求与战史一致，但不是精确测绘；村落级位置以地名标注为准。

改版只动界面、交互与气氛，以上数字与故事原文一字未改。

## 技术说明

- 单个 `index.html`，约 133 KB，纯手写，零第三方库、零资源文件、零构建步骤。
- 3D 用 Canvas 2D 自绘：透视投影 + 画家算法；地形是 48×48 高度场，顶点做定向光照，再用 marching squares 生成等高线；沙盘木框按朝向分前后两遍绘制以正确处理遮挡。
- 地形图层（地形、等高线、水系、铁路、刻线）在相机静止时缓存成位图，只做一次 blit；沉浸层（天光、雾、雪、颗粒）每帧重画，都是廉价渐变与批量矩形，静止与播放时稳定 60fps。
- 地平线按相机方位反解，日轮 / 月轮随视角转动，星点只在地平线以上绘制。
- 音场用 WebAudio：一路棕噪声过低通做风，一路随机触发的低频正弦包络做远处炮声，其余为界面短音；没有外部音频文件。
- 胶片颗粒是一张 140×140 的噪点 canvas 转成 dataURL 做背景，`mix-blend-mode: overlay`，不额外加载图片。
- 触屏可用（单指旋转、双指缩放），小屏有基础适配，但主要是桌面端体验。

## 部署到 GitHub Pages

1. 新建仓库，把本目录内容推上去（或网页端直接拖整个文件夹上传）。
2. Settings → Pages → Source 选 **Deploy from a branch**，分支 `main`，目录 `/ (root)`。
3. 等一两分钟，访问 `https://<用户名>.github.io/<仓库名>/`。

`index.html` 在根目录，无需任何构建配置。

### About (English)

A single-file, offline 3D sandbox of the Huaihai Campaign (6 Nov 1948 – 10 Jan 1949). Canvas 2D with hand-written perspective projection and a painter's algorithm — 48×48 height field, marching-squares contours, 24 real unit designations, 11 eyewitness-scale stories, 4 situation layers, 23 dated events. No dependencies, no assets, no build step: open `index.html`. Unit positions are illustrative day-by-day approximations, not survey data.

**Note:** the UI text and content are in Simplified Chinese; it is a historical-education piece, not a game.
